# Birthday site

Vite + React + TypeScript boilerplate with routes for home, a Spline 3D scene, games, and a gallery.

## Run

```bash
npm install
npm run dev
```

## Spline

1. In Spline, use **Export → Public URL**.
2. Copy `.env.example` to `.env`.
3. Set `VITE_SPLINE_SCENE_URL` to that URL.
4. Restart `npm run dev`.

Photos go in `public/photos`. Mini-games go in `src/games`.
